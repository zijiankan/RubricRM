# 奖励饱和过滤：GRPO 中的自发课程学习效应

## 问题：噪声梯度导致的熵崩塌

在 Group Relative Policy Optimization（GRPO）中，优势值通过在 prompt 组内归一化奖励来计算：

$$a_i = \frac{r_i - \mu_g}{\sigma_g}$$

其中 $\mu_g$ 和 $\sigma_g$ 分别是 prompt 组 $g$ 的奖励均值和标准差。当某个 prompt 的 $n$ 个 rollout 获得几乎相同的奖励时（*奖励饱和*），$\sigma_g \to 0$，归一化后的优势值退化为噪声。

这些噪声梯度并不会相互抵消——它们会**系统性地压缩策略熵**。其机制如下：

1. **策略梯度的不对称性**：增大"好" token 的概率和减小"差" token 的概率，都会使分布变得更加尖锐。
2. **自回归放大效应**：token 分布的微小尖锐化会在数百步生成过程中指数级放大，导致输出多样性崩塌。
3. **正反馈环路**：熵降低 → rollout 更相似 → 奖励饱和加剧 → 更多噪声梯度 → 熵进一步降低。

在我们的 T2I 评估任务实验中（Qwen2.5-VL-7B，每个 prompt 8 个 rollout），这种熵崩塌在三次独立训练中均稳定发生在第 33 步，尽管正则化强度各不相同（$\lambda_{\text{ent}} \in \{0.001, 0.01\}$，$\lambda_{\text{KL}} \in \{0, 0.01\}$），呈现出典型的**相变**特征。

## 方法：奖励饱和过滤

我们提出一个简单的修改：**将奖励饱和组的优势值归零**。

对于每个 prompt 组 $g$ 及其 rollout 奖励 $\{r_1, \ldots, r_n\}$，计算组内奖励标准差 $\sigma_g$。若 $\sigma_g < \tau$（阈值超参数），则将该组所有样本的优势值设为零：

$$a_i = \begin{cases} 0 & \text{if } \sigma_g < \tau \\ \frac{r_i - \mu_g}{\sigma_g} & \text{otherwise} \end{cases}$$

这实际上移除了饱和组的梯度贡献。被过滤的样本仍然正常参与前向和反向传播（保持分布式训练中 batch 大小的一致性），但对策略更新贡献零梯度。

**阈值选择**：默认使用 $\tau = 0.02$。对于输出范围为 $[0, 1]$、组大小 $n = 8$ 的奖励函数，该阈值过滤的是所有 rollout 之间差异小于 $\pm 0.02$ 的组——这些组几乎不包含任何有效的学习信号。

## 自发课程学习效应

饱和过滤机制无需显式设计，即可产生**自适应课程学习**效果：

| 训练阶段 | 模型能力 | 组内奖励分布 | 过滤行为 |
|---|---|---|---|
| 早期（第 0-10 步） | 较弱，高熵 | rollout 间奖励差异大 | 少量组被过滤（~5-10%），大部分梯度有效 |
| 中期（第 10-30 步） | 逐步提升 | 简单 prompt 饱和，困难 prompt 仍有差异 | 中等过滤（20-40%），焦点转向较难 prompt |
| 后期（第 30 步以后） | 较强 | 大多数 prompt 饱和，仅最难的仍有区分 | 大量过滤（40-60%），训练集中于能力边界 |

这产生了一个自然的**由易到难课程**：

- **阶段一**：模型从所有 prompt 中学习，在简单样本上快速提升。
- **阶段二**：随着简单 prompt 饱和（所有 rollout 表现相近），它们被自动排除。训练信号主要来自中等难度的 prompt。
- **阶段三**：只有最难的 prompt——模型仍能产生质量参差的输出——贡献梯度。模型被迫聚焦于自身最薄弱的能力维度。

这与*自步学习*（self-paced learning, Kumar et al., 2010）类似，但方向相反：不是从简单样本开始逐步添加困难样本，而是从所有样本开始，**逐步移除已掌握的样本**。课程效应自发涌现于模型能力提升与固定过滤阈值的交互之中，无需显式的难度标注或调度策略。

## 与替代方法的对比

| 方法 | 机制 | 局限性 |
|---|---|---|
| 熵正则化（$\lambda_{\text{ent}}$） | 在损失函数中加入熵奖励项 | 未解决噪声根源；需精细调参；可能与任务所需的策略聚焦冲突 |
| KL 惩罚（$\lambda_{\text{KL}}$） | 惩罚策略偏离参考模型 | 约束整体漂移，但无法区分噪声梯度与有效梯度 |
| 学习率衰减 | 降低所有梯度幅度 | 有效学习与噪声学习被同等减缓 |
| **奖励饱和过滤**（本方法） | 移除无信息组的梯度 | 直击噪声根源；保持有效样本的完整学习速度；自发产生课程学习效应 |

核心区别在于：饱和过滤是**选择性的**——它只移除噪声、保留信号；而基于正则化的方法则对信号和噪声施加均匀的衰减。

## 实现

该方法仅需对 GRPO 优势值计算进行最小修改：

```python
# 在 compute_grpo_outcome_advantage() 中
for group_id in unique_groups:
    group_rewards = rewards[group_id]
    group_std = std(group_rewards)
    if group_std < threshold:
        advantages[group_id] = 0  # 饱和组梯度归零
    else:
        advantages[group_id] = (group_rewards - mean(group_rewards)) / group_std
```

此外，我们将 `saturation_filtered_ratio`（每个 batch 中被过滤组的比例）作为训练诊断指标进行记录，它同时也是模型对训练分布掌握程度的一个代理指标。
